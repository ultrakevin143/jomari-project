# Operations console

Mode: Operate. Primary task: identify service exceptions and trace them to records, imports, and quality checks. User confirmed municipal operations focus and direct implementation in code.

## Direction contract

THESIS: A legible municipal control desk; the overview starts with service completion and exceptions, then data trust.

OWN-WORLD: Cool off-white canvas, white work surfaces, deep blue-gray navigation, restrained evergreen actions, tabular numbers, compact tables, one system sans family, crisp Lucide line icons. Green, amber, and red always accompany words.

STORY: Read the reporting period, assess collection completion and missed stops, inspect source freshness, then follow a real exception into its source or failed record.

FIRST VIEWPORT: A 232px desktop sidebar, compact header, reporting-period line, four purposeful metrics, a wide daily collection chart beside a source-status panel, followed by route exceptions. The import action lives on the integration page. Mobile uses a Sheet menu and stacked metrics.

FORM: Brief-pinned administrative console (no open visual-world tournament); service hierarchy and working drill-downs determine structure. Seed key: brief-pinned-operations. Signature interaction: a failed-record detail reveals its validation issue and a corrected-payload retry without reprocessing successful rows.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
